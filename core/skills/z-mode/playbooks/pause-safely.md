# Pause safely

Only when the user asks to stop or pause.

1. Finish or back out of the current step. Start nothing new.
2. Take no irreversible action. Do not push.
3. Leave the work recoverable. Either commit it locally as `wip:` on the
   current branch, or leave it uncommitted and list the files. Say which.
4. Update the task readme: what is done and verified, current state, next
   steps, key files, and gotchas.

Reply: the state of the tree, the commits made, and the first action on resume.
