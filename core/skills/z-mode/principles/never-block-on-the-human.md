# Never block on the human

The user supervises asynchronously. For reversible work, decide, proceed, and
report the result so the user can correct it.

- Do not ask "should I do X?" for reversible local work. Do X and say why.
- Still ask before irreversible or outward-facing actions: deleting data,
  force-push, pushing, sending mail, changing host state as root.
- Product and upstream direction come from the user. Execution does not wait.
